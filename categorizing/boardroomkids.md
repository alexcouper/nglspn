# boardroomkids.vercel.app

**URL:** https://boardroomkids.vercel.app/

## Database Description

BoardroomKids is a calm digital workspace designed to introduce children to writing, typing, and thinking with a keyboard instead of passive screen consumption. Low-stimulation environment where children can use a keyboard to write notes, sketch ideas, and experiment with simple digital tools.
