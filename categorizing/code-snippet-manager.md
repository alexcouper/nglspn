# Code Snippet Manager

**URL:** https://code-snippet-managment.vercel.app

## Database Description

Snippet Manager is a developer tool for storing, organizing, and sharing code snippets in one place. Supports multiple files (blueprints), public community library, private personal snippets with secret share links, private team workspaces with invite codes, threaded comments, Google and Microsoft OAuth.

## Product Overview

Code Snippet Manager is a web-based developer tool built with Next.js for saving, organizing, and sharing code snippets. The landing page presents a clean, minimal split-screen layout with authentication options on the left and a feature overview on the right. The platform supports saving snippets in any programming language, with a distinctive "blueprints" feature that allows users to bundle multiple related files together in a tabbed interface (for example, grouping a database config, middleware, and environment file into a single shareable unit). Key features include a public community library where developers can browse and contribute shared snippets, private personal snippet storage, secret URL sharing for private snippets, and private team workspaces that members can join via invite codes. Search and filtering by language, tags, and keywords helps users find snippets quickly. Authentication is handled through Google and Microsoft OAuth with instant sign-in and no approval process. The tech stack includes Next.js and React on the frontend with TypeScript and Tailwind CSS (using shadcn/ui components), a .NET 10 Web API backend, and PostgreSQL on Neon for the database, deployed across Vercel and Render.
