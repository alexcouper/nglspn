# codeclip.link

**URL:** https://www.codeclip.link/

## Database Description

Dead simple code snippet sharing. Paste code, get link, done. Auto-detects 20+ languages with syntax highlighting. Private by default, expires in 10 days. No sign-up. Made with Next.js, Supabase, TypeScript.

## Product Overview

CodeClip is a minimalist code snippet sharing tool positioned as a modern pastebin alternative. The site presents a clean, single-purpose interface: users paste code into an editor, and the tool generates a shareable link immediately -- no account creation or configuration required. It auto-detects over 20 programming languages and applies syntax highlighting, making shared snippets easy to read. Snippets are private by default and expire after 10 days, which keeps things ephemeral and low-maintenance. The tech stack is Next.js on the frontend with Supabase (PostgreSQL) for storage, deployed on Vercel. The overall experience is focused on speed and simplicity -- there are no dashboards, folders, or collaboration features, just a fast path from code to shareable link.
