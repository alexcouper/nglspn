# open.mannvaen.is

**URL:** https://open.mannvaen.is/

## Database Description

A directory mapping open-source projects with connections to Iceland. Documents projects developed by Icelandic individuals, organizations, or institutions. Aims to make the Icelandic open-source ecosystem visible, support collaboration, and strengthen long-term digital self-reliance. Community-driven.

## Product Overview

open.mannvaen.is ("Íslenskur opinn hugbúnaður") is a curated, community-driven directory that catalogues open-source software projects with ties to Iceland. The site is operated by Samtök um mannvæna tækni (the Association for Humane Technology) and serves as a discovery and visibility platform for the Icelandic open-source ecosystem.

Key features observed on the site:

- **Project directory** - A browsable listing of open-source projects at `/projects` ("Verkefni"), allowing visitors to explore what Icelandic developers and organizations are building in the open.
- **Community submissions** - Anyone can submit a project via the `/submit` page ("Bæta við verkefni"), making the directory community-driven rather than centrally curated.
- **Bilingual support** - The interface supports both Icelandic and English, with a language toggle in the header.
- **Dark/light theme** - Built-in theme switching with system preference detection.
- **Bug reporting** - A footer link to report issues via email to info@mannvaen.is.

The site is built with Next.js (likely scaffolded with v0.dev based on the meta generator tag), uses Tailwind CSS for styling, and is deployed on Vercel. The tech stack and clean, minimal design suggest a focused community tool rather than a commercial product. Its primary value is making the scattered Icelandic open-source landscape discoverable in one place, encouraging collaboration and reducing duplication of effort.
