# postwall.app

**URL:** https://postwall.app

## Database Description

PostWall is a free-to-post-it application. Works for collaborating across a single "Wall" (after you log in). It stores your wall in localstore until you log in, and then you can save and have multiple walls. Built because I didn't have a freely accessible, similar solution and needed to ideate and organize thoughts.

## Product Overview

*Note: Unable to visit the live site; this summary is based on available project metadata.*

PostWall is a collaborative digital whiteboard centered around virtual sticky notes. Users can create a "Wall" and add, arrange, and organize post-it style notes directly in the browser. The app works without an account by persisting data in local storage, lowering the barrier to entry for quick brainstorming sessions. Once a user logs in (via Firebase authentication), they can save their walls to the cloud (Firestore) and manage multiple walls. The real-time collaboration layer allows multiple users to work on the same wall simultaneously. Built with React and Vite, it is a lightweight, browser-based tool aimed at individuals or small teams who need a free, no-friction space for ideation and thought organization -- an alternative to heavier tools like Miro or MURAL.
