# rocketleague.is

**URL:** https://www.rocketleague.is/

## Database Description

RLIS Fantasy League. Fantasy league website for the Icelandic Rocket League league (RLIS). Users build dream teams and compete weekly. Features: Dream team selection, roles with 2x bonus, weekly scoring, leaderboard, player overview, transfers. Built with Next.js, Supabase, Tailwind CSS, shadcn/ui on Vercel.

## Product Overview

rocketleague.is is a fantasy league platform built around the Icelandic Rocket League competitive scene (RLIS). It allows users to assemble their own "dream teams" by selecting real RLIS players, then compete against other fantasy managers based on weekly match performance. Key features include a dream team builder where users pick players and assign roles that grant a 2x scoring bonus, a weekly scoring system tied to actual RLIS match results, a leaderboard ranking all fantasy participants, a player overview section for browsing available players and their stats, and a transfer system for swapping players between weeks. The tech stack is a modern web app built with Next.js on the frontend, Supabase (PostgreSQL) for the backend and auth, styled with Tailwind CSS and shadcn/ui components, and deployed on Vercel. It serves a niche but engaged community of Icelandic Rocket League fans who want a deeper layer of engagement with the local esports league.
