# smakk.app

**URL:** https://smakk.app/

## Database Description

Smakk.app is a lightweight web app for rating beers with friends and discovering your favorites together. Create a tasting session, invite others to join, and rate beers in real time. No accounts, no friction.

## Product Overview

Smakk is a mobile-first social beer tasting web application built with Nuxt (Vue.js) and Supabase. The landing page features the tagline "Let's find your favorite beer" and invites users to rate beers with friends and discover favorites together. The core workflow is straightforward: a user creates a tasting session, invites friends to join, and everyone rates beers across 5 categories in real time to see which beer wins. The app is designed as a progressive web app (PWA) with full iOS splash screen support, meaning it can be installed on a phone's home screen for a native-like experience. It requires no account creation and is free to use. The app uses Supabase for real-time data synchronization, enabling live collaborative rating sessions. Analytics are handled via Fathom. It was created by a developer named Valgeir.
