# sundlaugar.com

**URL:** https://sundlaugar.com

## Database Description

Nýleg endursmíði á Sundlaugalistanum. Mætti kannski kalla 2.0. Nú með multi-check-in, stjörnur og meðmæli, badges, leaderboard og sundlaugakóngur/drotting. Betra mobile (PWA) og "finna næstu laug". Margt fleira í Claude pípunum.

## Product Overview

Sundlaugar.com is a rebuilt and modernized version of "Sundlaugalistinn" (The Swimming Pool List), an Icelandic directory and community platform for public swimming pools across Iceland. The site is built with Next.js and features a clean, modern UI with navigation for browsing pools ("Sundlaugar") and a leaderboard ("Stigatafla").

The platform goes well beyond a simple directory. Users can create accounts and check in to pools they visit (with multi-check-in support), rate pools with stars, leave reviews/recommendations, and earn badges for their swimming activity. A gamification layer includes a leaderboard system and the title of "sundlaugakóngur/drottning" (swimming pool king/queen) for top visitors. The site is delivered as a Progressive Web App (PWA) for a native-like mobile experience and includes geolocation features to help users find the nearest pool. The tech stack includes Next.js on Vercel with Supabase as the backend, and the project description notes that further AI-powered features are in the pipeline.

- **Travel & Local Discovery** - Functions as a geo-aware directory for finding and exploring swimming pools across Iceland, useful for both locals and tourists.
- **Consumer Products** - A consumer-facing web/PWA app designed for everyday personal use.
