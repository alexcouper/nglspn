# Synapse - Watch AI Agents Think in Real-Time

**URL:** https://synapse.andri.is/

## Database Description

SYNAPSE makes AI reasoning visible. When an AI agent works on a task — reading files, searching the web, writing code, making decisions — SYNAPSE renders every step as a live, interactive node graph. Features Watch Bubbi, Demo Mode, Upload, Live Mode. All code written by AI agent. Stack: Next.js, React Flow, Tailwind CSS, Framer Motion, Zustand, Pusher, SearXNG, OpenClaw.

## Product Overview

Synapse is a visualization tool that renders AI agent reasoning and decision-making as live, interactive node graphs. Rather than treating AI workflows as opaque black boxes, Synapse exposes every step an agent takes — file reads, web searches, code generation, branching decisions — as connected nodes in a flowchart-like interface built with React Flow. The tool offers several modes of interaction: "Watch Bubbi" lets users observe a specific AI agent (Bubbi) working in real time; Demo Mode provides a pre-recorded walkthrough of agent behavior; Upload Mode allows users to load their own agent trace data for visualization; and Live Mode connects to a running agent session via Pusher for real-time streaming of reasoning steps. The frontend is built with Next.js, styled with Tailwind CSS, and uses Framer Motion for smooth node animations and transitions. State management is handled by Zustand, and the project integrates SearXNG (a privacy-respecting metasearch engine) and OpenClaw as part of the agent toolchain. The entire codebase was written by an AI agent, making it a self-referential showcase of AI-assisted development. It is open source, deployable via Docker or Vercel, and serves as both a developer tool for debugging agent workflows and an educational/demonstration tool for understanding how AI agents operate.
