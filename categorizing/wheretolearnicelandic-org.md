# wheretolearnicelandic.org

**URL:** https://wheretolearnicelandic.org

## Database Description

A centralized platform for Icelandic language learning resources. Compiles language schools, courses, self-study methods, mobile apps, and private teachers. Built with Docusaurus, Strapi CMS, Algolia search. Received over 2,000 visitors on first day. Community-driven.

## Product Overview

Where to Learn Icelandic is a community-driven resource directory that serves as a one-stop guide for anyone looking to learn the Icelandic language. The site aggregates and organizes a wide range of learning resources including language schools (both in Iceland and online), structured courses, self-study materials, mobile apps, and listings for private teachers and tutors. Built on Docusaurus (a documentation-focused static site generator) with a Strapi CMS backend for content management and Algolia-powered search for fast resource discovery, the platform is designed to make it easy to find and compare different learning options. The site appears to be community-driven, meaning users or contributors can suggest and add new resources over time. Its strong initial traction (over 2,000 visitors on launch day) suggests it fills a real gap in the Icelandic language learning ecosystem, where resources have historically been scattered across many different sites. The target audience includes immigrants to Iceland, heritage speakers, language enthusiasts, and anyone interested in learning Icelandic regardless of their location.

Note: This overview is based on the database description rather than a live site visit, as the site could not be fetched at the time of writing.
