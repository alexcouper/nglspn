## Site Overview

Yrda is an Icelandic web dictionary (vefordabok) that consolidates word definitions, grammatical inflections (declensions and conjugations), and other linguistic data into a single, clean interface. The dictionary contains over 56,000 entries drawn from Icelandic language datasets (open data sources).

Key features observed:

- **Word lookup with autocomplete** - The app loads with initial suggestions and supports searching across the full dictionary.
- **Word definitions (ordskyringar)** - Each entry includes Icelandic-language definitions with numbered senses and usage examples.
- **Grammatical inflections (beygingar)** - Entries include declension/conjugation tables sourced from BIN (Beygingarlis islensks nuttimamols, the Database of Icelandic Morphology).
- **Cross-references (tilvisanir)** - Entries link to related words and phrases.
- **Idiomatic expressions (ordastodur/ordtok)** - Common phrases and idioms are included within entries.
- **Light/dark theme support** - The UI supports both light and dark mode.
- **Single-page application** - Built with Vite and TypeScript, delivering a fast, responsive experience.
- **Open data driven** - Combines data from multiple Icelandic language resources.

The tech stack includes TypeScript, Vite, Bun, and Docker, consistent with the tags in the database.
