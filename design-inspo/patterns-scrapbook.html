1. App Store "Today" Tab — Editorial Cards

Apple's approach: large hero images, editorial storytelling, mixed card sizes

The Pattern

Source: Apple Developer — Getting Featured

Mixed card sizes Editorial storytelling Full-bleed hero images Category labels (not tags)

Key technique: The hero card is NOT just a bigger version of the small card. It tells a story — "App of the Day", "How we built X", a curated collection. The small cards below are the actual browsable items.

Insight: Categories appear as subtle labels ABOVE the title, not as colored badge clutter ON the card. This keeps cards clean while still communicating what type of thing this is.

Artifacts needed per project

  • Hero banner image (16:9 or wider) — AI-generated scene/lifestyle shot
  • App icon (square, rounded corners) — for compact card view
  • Editorial tagline — 1 sentence that sells the project's story
  • Category assignment — singular category, not multiple tags

2. Product Hunt — Compact List Items

Product Hunt's approach: horizontal list items, icon-led, social proof via upvotes

The Pattern

Source: Product Hunt

┌─────────────────────────────────────────────────────┐ │ ┌────┐ Project Title ▲ 152 │ │ │Icon│ One-line tagline describing... │ │ │ └────┘ 💬 24 · 🏷 Developer Tools │ ├─────────────────────────────────────────────────────┤ │ ┌────┐ Another Project ▲ 87 │ │ │Icon│ Brief description of what it... │ │ │ └────┘ 💬 12 · 🏷 Consumer App │ ├─────────────────────────────────────────────────────┤ │ ┌────┐ Third Project ▲ 43 │ │ │Icon│ What this project does in... │ │ │ └────┘ 💬 6 · 🏷 Community │ └─────────────────────────────────────────────────────┘
Icon-led (not image-led) Single-line tagline Social proof (votes) Minimal metadata

Key technique: Extremely information-dense. Each item shows only: icon, title, tagline, engagement count, ONE category. No tags, no banners, no clutter. The icon does the visual heavy lifting.

Insight: The category appears as a single subtle label, not a collection of tags. This answers "what kind of thing is this?" without visual noise.

Artifacts needed per project

  • Square icon (256×256) — distinctive, recognizable at small size
  • Tagline — max ~60 chars, one line
  • Category — single primary category

3. Setapp Marketplace — Curated Sections

Setapp's approach: horizontal scrolling sections, quality ratings, platform badges

The Pattern

Source: Setapp Marketplace

[Discover] [All Apps] [Optimize] [Work] [Create] [Develop] ───────────────────────────────────────────────────────────── ★ TOP RATED See all → ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ App Name │ │ App Name │ │ App Name │ │ App Name │ │ Tagline │ │ Tagline │ │ Tagline │ │ Tagline │ │ 97% ·Mac │ │ 99% ·iOS │ │ 95% ·Web │ │ 98% ·Mac │ └──────────┘ └──────────┘ └──────────┘ └──────────┘ 🆕 NEW ARRIVALS See all → ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ App Name │ │ App Name │ │ App Name │ │ App Name │ │ Tagline │ │ Tagline │ │ Tagline │ │ Tagline │ │ 🔥 Hot │ │ Mac, iOS │ │ Web │ │ Mac │ └──────────┘ └──────────┘ └──────────┘ └──────────┘
Category tabs (top nav) Curated sections Horizontal scroll Quality ratings Platform badges

Key technique: Categories are top-level tabs, not tag filters. Within each category view, projects are organized into editorial sections ("Top rated", "New arrivals", "AI apps"). This feels curated rather than a database dump.

Insight: The filtering is built INTO the page structure (tabs + sections) rather than being a separate filter sidebar. Users browse by interest, not by clicking checkboxes.

Artifacts needed per project

  • Square icon — clean, recognizable
  • Tagline — short, action-oriented ("Extract text from visuals")
  • Category — maps to a tab
  • Quality/rating signal — could be community rating or editorial pick

4. Vercel Marketplace — Integration Directory

Vercel's approach: clean grid, icon + name + description, category sidebar

The Pattern

Source: Vercel Marketplace

┌──────────┬──────────────────────────────────────────┐ │ Categories│ │ │ │ ┌─────────┐ ┌─────────┐ ┌─────────┐ │ │ ○ All │ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ │ ● Storage│ │ Name │ │ Name │ │ Name │ │ │ ○ AI │ │ 2-line │ │ 2-line │ │ 2-line │ │ │ ○ Auth │ │ desc │ │ desc │ │ desc │ │ │ ○ CMS │ └─────────┘ └─────────┘ └─────────┘ │ │ ○ Logging│ │ │ ○ Mail │ ┌─────────┐ ┌─────────┐ ┌─────────┐ │ │ │ │ [Icon] │ │ [Icon] │ │ [Icon] │ │ │ │ │ Name │ │ Name │ │ Name │ │ │ │ │ 2-line │ │ 2-line │ │ 2-line │ │ │ │ │ desc │ │ desc │ │ desc │ │ │ │ └─────────┘ └─────────┘ └─────────┘ │ └──────────┴──────────────────────────────────────────┘
Sidebar categories Icon-led cards Minimal info per card Professional/clean

Key technique: Very clean and professional. Each card shows just icon + name + 2-line description. Categories in sidebar act as a radio-button filter (one at a time). No tags on cards at all.

Insight: When cards are this clean, the grid itself becomes the visual pattern. The icons do all the differentiation work.

Artifacts needed per project

  • Square icon — must work at ~48px
  • 2-line description — what it does, concisely
  • Single category

5. Dribbble/Behance — Visual-First Gallery

Design portfolio approach: image IS the card, text is secondary

The Pattern

Source: Dribbble, Behance

┌───────────────┐ ┌───────────────┐ ┌───────────────┐ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░ FULL ░░░░░░│ │░░░ FULL ░░░░░░│ │░░░ FULL ░░░░░░│ │░░░ IMAGE ░░░░░│ │░░░ IMAGE ░░░░░│ │░░░ IMAGE ░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ │░░░░░░░░░░░░░░░│ ├───────────────┤ ├───────────────┤ ├───────────────┤ │ Title │ │ Title │ │ Title │ │ Author · ♥ 42 │ │ Author · ♥ 87 │ │ Author · ♥ 23 │ └───────────────┘ └───────────────┘ └───────────────┘
Image-dominated cards Minimal text overlay Visual browsing Masonry grid option

Key technique: The image IS the product. Cards are 80%+ image, with just title and author below. Works beautifully when you have high-quality visuals. Falls apart without them.

Insight: This pattern demands excellent imagery. If even 20% of projects have poor images, the whole page looks bad. This is the highest-reward but highest-investment approach.

Artifacts needed per project

  • Hero image (4:3 or 16:9) — must be high quality, AI-generated if needed
  • "In-use" screenshot — showing the product in context
  • Title + author — minimal text

Key Techniques Comparison

🏷 How they handle categories

App Store: Label above title
Product Hunt: Single tag after metadata
Setapp: Top tabs (no labels on cards)
Vercel: Sidebar radio buttons
Dribbble: Tags on detail page only

🖼 How they handle images

App Store: Hero banners + icons
Product Hunt: Icons only (64px)
Setapp: Icons only
Vercel: Icons only (48px)
Dribbble: Full-bleed images

📝 What text appears on card

App Store: Category + title + tagline
Product Hunt: Title + tagline + votes
Setapp: Title + tagline + rating
Vercel: Title + 2-line description
Dribbble: Title + author

🔍 How filtering works

App Store: Category tabs + editorial
Product Hunt: Topic pages
Setapp: Category tabs
Vercel: Sidebar radio categories
Dribbble: Tags + search

Which direction resonates most?

Click to select — you can pick multiple. We'll discuss in the terminal.

A. App Store Editorial

Hero banners, mixed card sizes, editorial sections, category labels. High visual impact, needs banner images per project.

B. Product Hunt Compact

Icon-led list items, dense info, social proof. Efficient, needs great icons. Lower image investment.

C. Setapp Curated Sections

Category tabs, curated sections (Top Rated, New), horizontal scrolling. Feels hand-picked. Icons + taglines.

D. Vercel Clean Grid

Minimal cards, sidebar categories, professional. Very clean but less "exciting". Lowest artifact needs.

E. Dribbble Visual Gallery

Image-dominated cards, visual browsing. Highest visual impact but requires excellent imagery for every project.

F. Hybrid Approach

Mix elements — e.g. App Store editorial sections + Setapp tabs + icon-led cards. Cherry-pick the best bits.
